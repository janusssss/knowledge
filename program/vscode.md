## 编辑操作 

- **Ctrl + C/V/X** - 复制/粘贴/剪切
- **Ctrl + Z/Y** - 撤销/重做
- **Ctrl + D** - 选择当前单词的下一个匹配项
- **Ctrl + F2** - 选择所有相同内容
- **Ctrl + /** - 注释/取消注释当前行
- **Alt + Shift + ↓/↑** - 向下/向上复制当前行
- **Alt + ↓/↑** - 向下/向上移动当前行
- **Ctrl + Shift + K** - 删除当前行

## 🔍 搜索和替换 

- **Ctrl + F** - 当前文件中查找
- **Ctrl + H** - 当前文件中替换
- **Ctrl + Shift + F** - 全局搜索
- **Ctrl + Shift + H** - 全局替换

## 📁 文件操作 

- **Ctrl + N** - 新建文件
- **Ctrl + O** - 打开文件
- **Ctrl + S** - 保存
- **Ctrl + Shift + S** - 另存为
- **Ctrl + W** - 关闭当前文件

## 🖱️ 导航 

- **Ctrl + P** - 快速打开文件
- **Ctrl + Tab** - 切换文件
- **Ctrl + G** - 跳转到指定行
- **F12** - 跳转到定义
- **Alt + ←/→** - 后退/前进

## 🎛️ 界面操作 

- **Ctrl + B** - 切换侧边栏显示
- **Ctrl + `** - 切换终端
- **Ctrl + J** - 切换面板显示
- **F11** - 全屏模式
- **Ctrl + Shift + E** - 显示资源管理器
- **Ctrl + Shift + F** - 显示搜索面板
- **Ctrl + Shift + G** - 显示Git面板
- **Ctrl + Shift + D** - 显示调试面板
- **Ctrl + Shift + X** - 显示扩展面板

## 🐞 调试 

- **F5** - 开始调试
- **F9** - 切换断点
- **F10** - 单步跳过
- **F11** - 单步进入

## ⚡ 其他实用快捷键 

- **Ctrl + Shift + P** - 命令面板
- **Ctrl + K, Ctrl + C** - 添加行注释
- **Ctrl + K, Ctrl + U** - 删除行注释
- **Ctrl + Shift + [** - 折叠代码块
- **Ctrl + Shift + ]** - 展开代码块
