### 概述
top 是一个在 Linux 和类 Unix 系统（如 macOS）中用于实时监控系统性能的命令行工具。它可以动态地显示当前正在运行的进程信息以及系统的整体资源使用情况，是系统管理员和开发者进行性能诊断和故障排查的重要工具。

### 交互命令
```bash
top 的强大之处在于其丰富的交互式命令，无需退出即可进行操作：

q：退出 top。

h 或 ?：显示帮助信息。

k：终止一个进程。会提示你输入要终止的进程PID。

r：重新设置一个进程的 nice 值（优先级）。

P：按 CPU 使用率排序（默认方式）。

M：按内存（RES）使用率排序。排查内存问题时非常有用。

T：按 CPU 时间（TIME+）排序。

N：按 PID 排序。

1：展开显示所有CPU核心的单独使用情况，而不是显示一个总的平均值。

u：然后输入用户名，只显示属于该用户的进程。

f：进入字段管理界面，可以选择在列表中显示或隐藏哪些列。

Shift + > 或 <：在排序后，向右或向左移动排序列。

Z：改变颜色方案。

W：将当前的 top 设置（如排序、显示的列等）写入配置文件（~/.toprc），下次启动时会沿用。

# 恢复默认设置 rm ~/.toprc
```
