### 概念

​	GUI（Graphical User Interface，图形用户界面）是用户与计算机系统交互的可视化方式。

### 显示服务器协议

| 特性   | x11(传统)              | wayland(主流)    |
| ------ | ---------------------- | ---------------- |
| 架构   | 客户端-服务器          | Compositor中心化 |
| 安全性 | 应用程序可监听所有输入 | 严格的权限控制   |
| 性能   | 通过网络协议通信       | 直接内存共享     |
| 复杂性 | 协议复杂，历史悠久     | 协议简洁，现代化 |

### QT

​	**Qt**是一个跨平台的C++图形用户界面应用程序开发框架。
