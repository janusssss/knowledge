# 步骤
1. 设置IOMMU(Input/Output Memory Management Unit)
2. 设置VFIO(Virtual Function I/O)
3. 虚机设置GPU

# IOMMU
将设备的DMA（直接内存访问）请求从设备虚拟地址转换为物理地址，为不同设备或虚拟机提供独立的内存访问空间。

# VFIO
VFIO 是 Virtual Function I/O（虚拟功能 I/O）的缩写。
它是 Linux 内核提供的一个框架，用于将主机硬件设备安全、高效地直接分配给虚拟机（VM）使用。
简单来说，它能让虚拟机绕过宿主机的操作系统，像宿主机一样直接控制和访问物理硬件（如显卡、USB控制器、网卡等）。
