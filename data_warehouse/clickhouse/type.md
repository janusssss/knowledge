### 字符串类型

| 类型              | 概述                           |
| ----------------- | ------------------------------ |
| `String`          | 可变长度字符串，无长度限制     |
| `FixedString(N) ` | 固定长度字符串，不足用 \0 填充 |

### 整数类型

| 类型     | 概述                      |
| -------- | ------------------------- |
| `Int8`   | -128 到 127               |
| `Int16`  | -32768 到 32767           |
| `Int32`  | -2147483648 到 2147483647 |
| `Int64`  | 64位有符号整数            |
| `UInt8`  | 0 到 255                  |
| `UInt16` | 0 到 65535                |
| `UInt32` | 0 到 4294967295           |
| `UInt64` | 64位无符号整数            |
