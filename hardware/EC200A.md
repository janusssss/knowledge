树莓派配置 Quectel EC801E-CN 4G 模块上网完整流程总结

一、硬件连接与系统识别

1. 插入 4G 模块（USB 接口），系统自动加载驱动 rndis_host、cdc_ether，生成网络接口 eth1。
2. 检查识别：
   ```bash
   lsusb                     # 应看到 Quectel 设备 ID 2c7c:0903
   ip a                      # 出现 eth1，但状态 DOWN，无 IPv4
   ```

二、安装串口工具并强制加载 AT 命令端口

模块默认 RNDIS 模式不提供 /dev/ttyUSB*，需手动加载：

```bash
sudo modprobe option
sudo sh -c 'echo "2c7c 0903" > /sys/bus/usb-serial/drivers/option1/new_id'
# 联通
./quectel-CM -s 3gnet
# 广电
./quectel-CM -s cbnet
```

之后检查：

```bash
ls /dev/ttyUSB*            # 出现 ttyUSB0, ttyUSB1, ttyUSB2
```

安装串口工具（任选一种）：

```bash
sudo apt install minicom -y      # 或 picocom / screen
```

三、解决 SIM 卡识别问题（关键步骤）

连接 AT 端口（通常 ttyUSB2）：

```bash
sudo picocom -b 115200 /dev/ttyUSB2
```

发送命令检查 SIM 卡：

```
AT+CPIN?
```

若返回 +CME ERROR: 4（无卡）或 10（未就绪），则：

· 物理处理：拔出 SIM 卡，用橡皮擦擦拭金属触点，在卡背面垫 2~3 层纸增加压力，重新插入。
· 强制检测：
  ```
  AT+QSIMDET=1,0          # 关闭自动检测，强制启用
  AT+QSIMSTAT=1
  AT+CFUN=1,1
  ```
· 再次 AT+CPIN? 应返回 READY。

四、配置 APN 并注册网络

针对联通卡（本例 APN 3gnet）：

```
AT+CGDCONT=1,"IP","3gnet"       # IPv4 单栈
AT+CFUN=1,1                     # 重启模块
```

等待 20~30 秒，检查注册状态：

```
AT+CEREG?                       # 应返回 0,1 或 0,5（已注册）
AT+CSQ                          # 信号值 10~31 为佳
```

退出串口工具：Ctrl+A，再按 Ctrl+X。

五、启动网络接口并获取 IP

```bash
sudo ip link set eth1 up
sudo dhclient eth1              # 获取 IPv4
ip -4 addr show eth1            # 应看到 192.168.43.100/24
```

测试 IPv4 连通性：

```bash
ping -I eth1 -c 4 8.8.8.8       # 成功则延迟 ~250ms
```

六、（可选）启用 IPv6 公网地址

默认只有 IPv4 私网地址，修改为双栈：

```bash
sudo picocom -b 115200 /dev/ttyUSB2
```

```
AT+CGACT=0,1                    # 去激活 PDP
AT+CGDCONT=1,"IPV4V6","3gnet"   # 改为双栈
AT+CGACT=1,1
AT+CFUN=1,1
```

重启后重新获取 IP：

```bash
sudo dhclient -r eth1
sudo dhclient eth1
ip -6 addr show eth1            # 应出现 2408:... 公网 IPv6
```

测试 IPv6：

```bash
ping6 -I eth1 2001:4860:4860::8888
```

七、设置路由（按需）

· 临时切换到 4G 上网（覆盖 WiFi 默认路由）：
  ```bash
  sudo ip route del default
  sudo ip route add default via 192.168.43.1 dev eth1
  ```
· 保持双网并存：使用策略路由或修改 dhcpcd.conf 中的 metric 值。

八、开机自动配置

编辑 /etc/dhcpcd.conf，添加：

```
interface eth1
metric 200
```

九、故障排查要点

现象 可能原因 解决办法
ls /dev/ttyUSB* 无设备 未加载 option 驱动 执行 modprobe option + echo ID > new_id
AT+CPIN? 返回 ERROR 4/10 SIM 卡接触不良 垫纸、清洁触点、重启模块
注册失败 +CEREG: 0,2/3 信号差或 APN 错误 检查天线、更换 APN（3gnet/wonet/cmnet）
eth1 状态 DOWN 未手动启动 ip link set eth1 up
能 ping 网关但 ping 不通外网 模块未附着数据网络 AT+CGATT? 应为 1，否则 AT+CGATT=1
修改 PDP 上下文报错 308 上下文激活中 先 AT+CGACT=0,1 再修改

十、最终验证

```bash
curl --interface eth1 ifconfig.me        # 显示公网 IPv4
curl --interface eth1 -6 ipv6.ip.sb      # 显示公网 IPv6
```

至此，树莓派上的 EC801E-CN 4G 模块可稳定提供 IPv4/IPv6 双栈互联网接入。
