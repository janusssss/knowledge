1.把需要烧录的BIOS文件名修改为PSPBIOS.IMG
2.把BIOSUBU.BIN、PSPBIOS.IMG，FORCE三个文件同时放到U盘（FAT32格式USB2.0 8G的） 根目录
3.刷BIOS时需搭配RYZEN4 9000系列CPU.

1. Change the BIOS file name to be burned to PSPBIOS.IMG
2. Put the three files BIOSUBU.BIN, PSPBIOS.IMG, and FORCE into the root directory of the USB flash drive (FAT32 format USB2.0 8G)
3. When flashing the BIOS, you need to use the RYZEN4 9000 series CPU.
4. Turn off the power! ! ! Remove all USB devices on the motherboard (including the mouse and keyboard)! ! !
5. Connect the USB flash drive to the USB port for one-click flashing BIOS, and press and hold the one-click flashing BIOS button until the blue indicator light turns on.
6. After updating the BIOS, the motherboard will automatically restart.
