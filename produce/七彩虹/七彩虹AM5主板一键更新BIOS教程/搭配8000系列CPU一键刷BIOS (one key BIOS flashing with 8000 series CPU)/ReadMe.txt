1.把需要烧录的BIOS文件名修改为PSPBIOS.IMG
2.把BIOSUBU.BIN、PSPBIOS.IMG，FORCE三个文件同时放到U盘（FAT32格式USB2.0 8G的） 根目录

4.按钮长按到蓝灯亮才松手。

1. Change the BIOS file name to be burned to PSPBIOS.IMG
2. Put the three files BIOSUBU.BIN, PSPBIOS.IMG, and FORCE into the root directory of a USB flash drive (FAT32 format USB2.0 8G)
3. When flashing the BIOS, you need to use a RYZEN4 8000 series CPU.
4. Press and hold the button until the blue light comes on.
