### 对比

| 类型              | 特点                       | 使用场景                       |
| ----------------- | -------------------------- | ------------------------------ |
| **etcd**          | 强一致性、小数据量         | 系统配置、服务发现             |
| **Redis**         | 高性能、多种数据结构       | 缓存、会话存储                 |
| **MongoDB**       | 文档存储、灵活模式         | 应用数据存储                   |
| **Elasticsearch** | 全文搜索、分布式、实时分析 | 日志分析、搜索引擎、数据可视化 |
