### 事务的四大特性（ACID）

| 特性   | feature     | 含义                                 |
| ------ | ----------- | ------------------------------------ |
| 原子性 | atomicity   | 要么全部成功，要么全部不成功         |
| 一致性 | consistency | 事务执行前后，数据库保持一致性状态   |
| 隔离型 | isolation   | 多个事务并发执行时，彼此之间互不干扰 |
| 持久性 | durability  | 事务提交后，对数据库的改变是永久的   |

### 并发问题

| 问题       | issue               | 含义                                               |
| ---------- | ------------------- | -------------------------------------------------- |
| 脏读       | dirty read          | 一个事务读取了另一个未提交事务的数据               |
| 不可重复度 | non-repeatable read | 在同一个事务中，多次读取同一数据返回不同的结果     |
| 幻读       | phantom read        | 在同一个事务中，多次执行相同的查询返回不同数量的行 |

### mysql四种隔离级别

| 隔离级别 | Isolation level  | 并发问题               |
| -------- | ---------------- | ---------------------- |
| 读未提交 | read uncommitted | 脏读、不可重复读、幻读 |
| 读已提交 | read committed   | 不可重复读、幻读       |
| 可重复读 | repeatable read  | 幻读                   |
| 串行化   | serializable     | 安全，但性能差         |

### 保证事务机制

| 机制     | 作用                             |
| -------- | -------------------------------- |
| undo log | 保证原子性和MVCC的版本回溯       |
| redo log | 保证持久性和崩溃恢复             |
| 锁机制   | 保证隔离型(行锁、间隙锁、意向锁) |
| MVCC     | 多版本并发控制，提高读取性能     |
| ReadView | 控制数据可见性，实现不同隔离级别 |
