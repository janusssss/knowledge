### 核心概念

​	Docker容器是基于Linux内核特性实现的轻量级虚拟化技术，主要利用了命令空间、控制组、联合文件系统三大核心技术实现的。

### 核心技术

| 技术         | technique         | 作用                                   | 内容                                     |
| ------------ | ----------------- | -------------------------------------- | ---------------------------------------- |
| 命名空间     | Namespace         | 实现资源隔离，容器拥有独立的系统试视图 | 进程、网络、文件系统、用户等资源相互隔离 |
| 控制组       | Cgroups           | 资源限制和监控                         | CPU、内存、磁盘I/O等使用量               |
| 联合文件系统 | Union File System | 实现镜像分层和写时复制                 | 节省存储空间，提高镜像构建效率           |
