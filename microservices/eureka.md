### 接口信息

| 接口路径                        | 返回信息                                |
| ------------------------------- | --------------------------------------- |
| `/eureka/apps`                  | 所有注册服务的名称、实例数量            |
| `/eureka/apps/<name>`           | 服务实例的 IP、端口、状态、健康检查 URL |
| `/eureka/status`                | 环境类型、运行时长、副本节点状态        |
| `/eureka/instance/<instanceId>` | 特定实例的详细信息                      |
