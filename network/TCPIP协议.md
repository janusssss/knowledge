# 概述
TCP/IP协议是互联网的核心通信协议套件，全称为传输控制协议/网际协议（Transmission Control Protocol/Internet Protocol）。它通过分层设计、IP寻址和端到端传输机制，实现了全球计算机设备的互联互通。

# 分层结构：四层模型
TCP/IP采用分层架构，每层负责特定功能，确保模块化与灵活性。

1. 应用层：用户应用程序，HTTP, HTTPS, FTP, DNS
2. 传输层：管理端到端的数据传输，确保可靠性与效率，TCP, UDP, SCTP
3. 网络层：处理数据包的路由与转发，实现跨网络通信，IP
4. 链路层：在物理介质（如以太网、Wi-Fi）上传输数据帧，Ethernet(以太网), WI-FI
