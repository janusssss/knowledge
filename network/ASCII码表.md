###  定义与背景

​	ASCII（American Standard Code for Information Interchange，美国信息交换标准代码）是计算机领域中最基础且广泛使用的字符编码标准之一。

- **本质**：ASCII是一种基于拉丁字母的字符编码方案，用**7位二进制数**表示128个字符（包括控制字符、数字、大小写字母、标点符号等）。
- **历史**：由美国国家标准协会（ANSI）于1963年制定，旨在解决不同计算机系统间文本数据交换的兼容性问题。
- **扩展**：后续出现**扩展ASCII**（8位，共256个字符），但缺乏统一标准，不同厂商可能定义不同的扩展字符集。
